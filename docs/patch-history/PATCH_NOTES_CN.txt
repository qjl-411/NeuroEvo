NeuroEvo-AD 工作台动态效果补丁 v7
=================================

本补丁基于已修复 3D 脑模型初始化问题的 v6 继续修改。

本次改动
--------
1. MRI 分析结果不再“瞬间跳出”
   - 从点击分析开始，界面至少保持约 3.2 秒的“正在分析 MRI”状态。
   - 这是纯展示层的最短呈现时间，不修改后端真实 latency_ms，不修改模型输出。
   - 如果后端本身耗时超过 3.2 秒，则不会额外强制再等待 3.2 秒。

2. 预测结果半圆环动态增长
   - 新分析完成后，从 0% 开始增长到真实 Softmax 目标值。
   - 动画约 1.85 秒，并带非常轻微的阻尼波动/收敛效果。
   - 中央百分比数字与圆弧同步增长。
   - 点击四个类别切换查看时，也会以约 0.72 秒平滑过渡到该类别真实概率。
   - 动画不修改真实概率值。

3. DMSA-Net 训练曲线逐步绘制
   - 五条真实训练指标曲线按 Epoch 从左向右逐步展开。
   - 总动画约 4.6 秒。
   - 曲线前沿有轻量扫描线/发光点，帮助表现“正在绘制”。
   - 图表视口会自动跟随曲线前沿，底部滑动条同步向右移动，最终到达曲线末端。
   - 用户主动拖动、滚轮或点击滚动控件后，会停止自动跟随，但曲线本身仍会继续绘制。
   - 最佳 Epoch 标记与摘要在曲线绘制完成后再出现。

4. 可访问性
   - 系统开启“减少动态效果 (prefers-reduced-motion)”时，会自动跳过长动画。

5. v6 3D 脑模型修复仍然保留
   - apps/web/src/landing/brainScene.js 与 v6 完全一致。

覆盖文件
--------
apps/web/src/pages/WorkspacePage.tsx
apps/web/src/pages/workspace.css
apps/web/src/landing/brainScene.js

建议覆盖方式
------------
只覆盖上面三个“文件”，不要用补丁中的 apps/web/src 文件夹整体替换原项目文件夹。

开发模式：
cd apps/web
npm run dev

生产构建：
cd apps/web
npm run build

校验
----
- WorkspacePage.tsx：TypeScript 严格模式语义检查通过（使用项目依赖 stub 做独立源码检查）。
- workspace.css：大括号结构平衡检查通过。
- brainScene.js：与 v6 修复版逐字节一致。
