一、研究中心 PDF 数据核查
------------------------
当前 neuroevo_papers.db：
- papers 总数：902
- Open Access 标记：844
- 有外部 pdf_url：748
- local_pdf_path 有值：0
- 项目压缩包内实际 .pdf 文件：0

结论：数据库目前存的是论文元数据 + 外部 PDF/落地页链接，不是 902 个 PDF 文件本体。
因此点“PDF”跳去出版社/开放获取网站、再由浏览器或迅雷下载，是在下载外部网站的文件。
项目已经有 apps/api/app/literature/pdf_download.py，可将开放获取 PDF 下载到 data/pdfs 并回写 local_pdf_path，
但当前这批数据库并没有执行完成这个本地化步骤。

二、顶部导航交互
----------------
1. 搜索图标：打开全局搜索面板，可快速导航，也可直接输入关键词进入研究文献检索。
2. 通知图标：打开通知中心；支持“全部标记为已读”，红点同步消失并保存在浏览器本地。
3. 用户区域：打开个人中心。
   - 游客：显示“访客 / 游客浏览”，可登录、注册或继续游客浏览。
   - 登录后：显示注册姓名与身份，并提供退出账号。

三、游客权限
------------
游客可浏览：首页、研究中心概览、模型证据中心。
游客不可：
- 进入 /workspace MRI 分析工作台
- 进入 /reports/search 执行研究文献检索
- 在研究中心直接提交文献检索（会弹出登录窗口）

直接输入受限 URL 时也会出现登录访问提示页。

四、关于账号系统的重要说明
--------------------------
这一版是“单机项目 / 演示环境账号系统”：账号和登录状态保存在当前浏览器 localStorage，密码只保存加盐后的哈希值，
不会以明文保存。它能真实完成注册、登录、退出、刷新后保持登录、游客权限限制。
但它不是生产级服务器认证：换电脑/换浏览器账号不会同步，懂前端的人也能绕过纯前端权限。
如果项目以后真正上线给多人使用，应再接 FastAPI 用户表 + 服务端 Session/JWT，并在后端同时保护推理和文献检索接口。
