NeuroEvo-AD 完整累计 UI 补丁
================================

这一个包已经把你目前需要的修改合在一起：

1. 新增“文献智能研究工作台”轮播图。
2. 新图最终位于第 3 张。
3. 原第 3 张 DMSA-Net 分析流程图移动到第 4 张。
4. 最终首页轮播共 4 张。
5. 去掉首页右侧浏览器原生纵向滚动条。
6. 首页、工作台、研究页等导航中的“报告中心”统一改为“研究中心”。
7. 不包含之前那版“轮播流畅度优化”，不会改 carousel JS、背景帧率或动画时长。

使用方法
--------

A. 把本 ZIP 解压。
B. 将里面的 NeuroEvo-AD_literature_full 文件夹复制到你现有项目所在位置，
   与现有同名文件夹合并。
   这样新的图片会自动落到：
   apps/web/public/assets/landing/literature-workspace-card4.png

C. 进入项目根目录，双击：
   APPLY_FULL_UI_PATCH.bat

D. 看到“累计 UI 补丁已完成”后，刷新：
   http://localhost:5173

为什么还需要双击一次 BAT？
-------------------------
你说你已经把之前覆盖过的文件删掉了，而当前项目可能是最初版本、也可能夹杂部分旧改动。
这个累计补丁会基于你“当前实际源码”做精确修改，避免用旧版整文件覆盖掉项目中其他内容。

安全性
------
运行前会自动备份它将修改的源码，备份目录类似：
.patch_backup_20260920_123456

如果想恢复，把备份目录里的文件按原路径复制回去即可。
