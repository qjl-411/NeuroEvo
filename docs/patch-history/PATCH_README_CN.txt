NeuroEvo-AD 工作台 UI 补丁 v3
===============================

适用基础：已应用上一版 Workspace UI 补丁，或直接用本补丁中的完整文件覆盖项目对应文件。

本版在上一版功能基础上，专门修正 DMSA-Net 模型性能图表左侧空白问题：

1. 当底部横向滑块位于最左端（0%）时，Y 轴 / Epoch 1 现在会贴近图表可视区域左侧，不再先出现一大块无效空白。
2. SVG 的响应式缩放对齐从默认居中改为左侧锚定（xMinYMid），避免在图表高度被响应式压缩时产生左侧 letterbox 空白。
3. 将绘图区左边距从 68px 收紧到 46px，同时保留足够空间显示 Y 轴刻度文字。
4. 将右侧绘图区边距从 68px 收紧到 58px，使有效绘图区更宽。
5. 对横向滚动 stage 增加显式左对齐防护，避免被其它布局规则意外居中。

覆盖文件：
- apps/web/src/pages/WorkspacePage.tsx
- apps/web/src/pages/workspace.css

说明：
- 本补丁保留上一版所有修改，包括预测类别可点击联动、中文 Grad-CAM 提示、可横向滚动的训练曲线等。
- 不修改后端、模型、权重、类别映射、推理逻辑和训练数据。

使用方法：
将本压缩包解压到 NeuroEvo-AD 项目根目录，覆盖同名文件，然后重新启动/构建前端。

开发模式：
cd apps/web
npm run dev

生产构建：
cd apps/web
npm run build
